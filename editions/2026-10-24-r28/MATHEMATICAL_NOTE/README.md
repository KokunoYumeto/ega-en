# Radicals and positive degrees in EGA II

This mathematical note explains the positive-degree radical convention in II, 2.1.10 and 8.2.10, proves the relevant implication and gives a nilpotent counterexample to equality with the radical in the whole ring. It is a separate companion to the English edition.

The modular source is `native/main.tex`; the complete standalone source is in `direct/`. Both contain the same text and formulas.

```powershell
./BUILD.ps1 -PdfLatex <pdflatex> -BibTeX <bibtex> -SourceForm native -OutputDirectory <new-directory>
```

Use `-SourceForm direct` for the standalone source. The standard LaTeX packages in its preamble must be installed.
