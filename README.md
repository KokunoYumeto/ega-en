# Elements of Algebraic Geometry — Cumulative English Edition

By Alexander Grothendieck and Jean Dieudonné.

Read EGA 0–IV in one linked, 1,410-page English reader, with separate readers
for EGA III and IV. Each reader is accompanied by its complete editable LaTeX
and a reproducible source project containing its inputs, macros, bibliography
and build instructions. Printed-witness translations are labelled separately.
The French original-language edition remains a distinct publication.

## Editorial scope

This edition incorporates the accepted English corrections through EGA Canon
R136. EGA IV, Part Three now gives the factors 2 in both images in §11.7.5,
the intended second reference in §11.9.8, the generator range starting at 1
in §11.9.10, and the quotient sheaf in §11.9.11. These four repairs appear in
both the cumulative and standalone IV-3 readers. The final reference in
§11.9.16 was already correct in this reader basis. Printed French remains
unchanged; printed errors and corrected English readings are distinguished.

The six unaffected standalone editions retain their exact previous PDF and
source bytes, with their dependencies checked against this source frontier.
The independently maintained III-1 branches remain separate and unchanged.
Later incoming reports are recorded separately and are not silently included.

Source provenance, inverse records, deterministic builds, the intended
mathematical-text changes, fonts, links and bounded visual checks passed.
This is an AI-assisted working edition, not independent human certification.
The native modular sources reproduce the released PDFs with the recorded
runtime. The direct cumulative LaTeX contains the same complete text; its
inherited one-line spacing/link-box difference on page 699 is documented in
the source ZIP. Use the native project for exact published pagination.
