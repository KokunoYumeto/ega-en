in a linked 1,410-page English edition covering EGA 0–IV. Standalone volumes
and separately labelled printed-witness translations are also included.
Every reader is accompanied by its complete editable LaTeX and a reproducible
source project containing all required project inputs and build instructions.

## Editorial scope

This edition incorporates accepted corrections to references, proof details
and notation in EGA IV, Parts Two and Three. The corresponding changes appear
in both the cumulative reader and the affected standalone volumes. Earlier
accepted corrections are retained. Five unaffected standalone editions preserve
their previous PDF, direct LaTeX and source ZIP bytes exactly. The French
original-language edition remains distinct; this English release does not
certify a new French reader. Later reports are recorded separately.

Source identities, exact changes, deterministic builds, fonts, reference targets
and bounded visual checks were verified. These checks are not independent human
certification of every mathematical assertion. The native modular sources
reproduce the released PDFs with the recorded runtime. The direct cumulative
LaTeX contains the complete text, with the inherited page-699 one-line spacing
and link-box difference documented in its source ZIP. The direct-source
page-970 rendering repair is reversible and changes no mathematical wording.
