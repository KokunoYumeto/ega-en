# Elements of Algebraic Geometry — Cumulative English Edition

By Alexander Grothendieck and Jean Dieudonné.

Read EGA 0–IV in one linked, 1,410-page English reader, with individual
readers for EGA III and IV. The maintained English text includes documented
corrections and scan-based transcription restorations. Printed-witness
translations are labelled separately; the French original-language edition
remains a distinct publication.

Start with the cumulative PDF, its complete editable LaTeX, or its reproducible
source project. Every reader below has both a direct complete `.tex` and a ZIP
containing its native inputs, macros, bibliography and build instructions.

## Scope and editorial status

This edition integrates accepted corrections through EGA Canon R128. The
III-1 current and printed-witness readers retain the exact 23 September bytes.
The native cumulative title and linked contents replace the former redundant
extra cover; no body page has been omitted. Later incoming reports are not
silently represented as included.

Source provenance, inverse records, deterministic replay, mathematical-text
changes, structure, fonts, links and bounded visual checks were verified.
This is an AI-assisted working edition, not independent human certification.
Native source projects reproduce the released PDFs with the recorded runtime.
The complete direct cumulative LaTeX has identical text, with a disclosed
one-line spacing difference on page 699; the ZIP controls exact pagination.
