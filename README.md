# Elements of Algebraic Geometry — English editions

**[Read the cumulative EGA 0–IV PDF](https://github.com/KokunoYumeto/ega-en/releases/download/ega-en-2026-10-23-r24/001_EGA_EN_CUMULATIVE.pdf)**

Alexandre Grothendieck and Jean Dieudonné’s *Éléments de géométrie algébrique* in English. The 1,411-page cumulative reader brings together the preliminaries of EGA 0 and Chapters I–IV: the language of schemes, the global study of morphisms, the cohomology of coherent sheaves, and the local study of schemes and morphisms.

Seven standalone readers accompany the cumulative edition. EGA III, Part One has separate corrected and diplomatic editions; the diplomatic translation preserves the printed mathematical readings. Each reader has an assembled LaTeX document and an editable source project containing its modular text, formulas, diagrams, styles, bibliography and build inputs.

The cumulative reader provides linked contents and cross-references. The standalone IV-1 and IV-4 PDFs do not contain hyperlinks. Some backmatter contents entries are repeated in the historical source arrangement. Original printed page markers and historical contents tables refer to the French pagination.

The source projects provide modular and assembled forms for pdfLaTeX, with build instructions in each project. Standard TeX packages and fonts are external dependencies. The III-1 diplomatic modular project includes its bibliography file.
