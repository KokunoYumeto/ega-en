# Elements of Algebraic Geometry — English edition

Alexandre Grothendieck and Jean Dieudonné's *Éléments de géométrie algébrique* in English.

A new English translation, made directly from the French transcription in
[ega-fr](https://github.com/KokunoYumeto/ega-fr), is in preparation and will be published here.
The French editions are available in [ega-fr](https://github.com/KokunoYumeto/ega-fr).
